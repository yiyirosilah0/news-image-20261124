A program that draws a one-page newspaper front page summing up the world news of Tuesday, 24 November 2026 — seven verified stories, from Gukesh v Sindarov's World Chess Championship opener in Geneva to Ariane 6 flying 36 Amazon satellites — and writes it to /output/entry.png. The image is drawn entirely in code (a hand-built 5x7 bitmap font and a small PNG encoder, Node standard library only): no network, no image files, and the same bytes come out of every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
